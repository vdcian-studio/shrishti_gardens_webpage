# Shrishti Gardens — A Serene Nature Stay in Kodaikanal

Standalone, high-performance static website for Shrishti Gardens boutique nature retreat at 2,133m in Kodaikanal, Tamil Nadu.

## Features
- Single-file standalone HTML webpage (index.html) with inlined styles and scripts
- 288-frame mountain mist canvas scroll scrubber
- Responsive Tailwind CSS design & luxury dark forest theme
- Interactive room folio, photo gallery lightbox, and live weather widget

## Live Preview
Double-click index.html or open directly in any browser.
